一、营业执照注册与经营范围

1.1 注册前关键设定

主体类型：有限责任公司（企业法人）。

注册资本：建议认缴不低于100万元——这是申请《增值电信业务经营许可证》的最低门槛（省内经营），低于100万将无法办证，直接影响平台收费撮合与微信平台型类目。

经营范围一次写全：登记后新增经营范围需变更登记，耽误整体进度。

1.2 经营范围条目（供勾选对照，最终以登记机关核定为准）

| 板块 | 经营范围条目 |
| --- | --- |
| 平台技术类 | 技术服务、技术开发、技术咨询、技术交流、技术转让、技术推广；软件开发；软件销售；信息系统集成服务 |
| 经营服务类 | 企业管理咨询；社会经济咨询服务；市场营销策划；供应链管理服务 |
| 广告类 | 广告设计、代理；广告制作；广告发布 |
| 居民家政类 | 居民日常生活服务；家政服务；家庭服务；劳务服务（不含劳务派遣） |
| 维修安装类 | 家用电器维修服务；家具安装和维修服务；日用电器修理；通用设备修理；专用设备修理 |
| 装修类 | 住宅室内装饰装修；建筑装饰材料销售；建筑材料销售；五金产品零售；家用电器销售；家具销售；卫生洁具销售 |
| 养老服务类 | 养老服务；居家养老服务；老年人养护服务；助餐、助洁、助浴服务；适老化改造服务 |
| 食品类 | 食品销售（仅销售预包装食品）；食品互联网销售（仅销售预包装食品）；食品销售；食品互联网销售 |
| 零售电商类 | 互联网销售（除销售需要许可的商品）；日用品销售；食用农产品零售 |
| 许可项目 | 第二类增值电信业务（信息服务业务）；食品经营（凭许可证经营）；建筑装饰装修工程施工（凭资质经营） |

1.3 办理流程

① 核名：当地市场监管部门企业名称自主申报系统核名。

② 提交设立登记：线上提交公司章程、股东信息、经营范围、注册地址证明等。

③ 领取执照：审核通过后领取营业执照正副本（或电子执照）。

④ 刻章备案：公章、财务章、法人章、发票章。

⑤ 税务登记：取得执照后30日内办理税务登记（新设企业通常已同步）。

周期：1～2周（视当地效率）。

二、增值电信业务经营许可证（经营性ICP）

2.1 适用判断（本项目必办）

平台对入驻商家收取佣金、信息服务费，即构成经营性互联网信息服务，需办理《增值电信业务经营许可证》（业务种类：信息服务业务，仅限互联网信息服务，俗称经营性ICP证）。

微信平台型类目与微信支付分账（平台商户）也要求提供主体一致的ICP许可证——不办将卡住类目申请和支付开通。

2.2 申请条件（《电信业务经营许可管理办法》）

| 条件 | 要求 |
| --- | --- |
| 主体 | 依法设立的公司 |
| 注册资本 | 省内经营≥100万元；全国或跨省经营≥1000万元 |
| 人员 | 有与经营活动相适应的专业技术人员（需提供社保证明） |
| 场地与设施 | 有必要的办公场地、设施及技术方案 |
| 信誉能力 | 有为用户提供长期服务的信誉或能力 |

2.3 申请材料

电信业务经营许可申请表。

营业执照副本及公司章程。

法定代表人身份证、专业技术人员社保证明。

验资报告或上年度审计报告（证明注册资本）。

业务发展可行性研究报告、技术方案（含平台功能、撮合模式、收费方式说明）。

网络接入协议或接入商证明材料。

2.4 办理流程与周期

通过工信部政务服务平台或属地通信管理局线上提交申请。

流程：提交→形式审查→受理→实质审核→批准发证。

周期：约1～3个月，是整体进度最长的关键项，建议营业执照到手后立即申请。

提示：经营范围须已含“第二类增值电信业务”相关表述，若执照未含需先变更。

三、食品相关证照与网络食品平台备案

3.1 平台自身：食品经营许可证

平台自营销售食品（含预包装以外的散装、生鲜、餐饮现制）需办《食品经营许可证》。

仅销售预包装食品可免许可，仅需备案（多证合一）；但本项目含生鲜与餐饮现制，须办证。

许可经营项目建议覆盖：预包装食品销售、散装食品销售、热食类食品制售等（以实际业务勾选）。

办理：属地市场监管部门，材料含营业执照、场所证明、食品安全管理制度等，周期2～4周。

3.2 网络食品交易第三方平台备案（平台撮合食品必办）

依据《网络食品安全违法行为查处办法》：平台提供者应在通信主管部门批准后30个工作日内，向所在地省级市场监管部门备案，取得备案号。

即：取得经营性ICP证（或ICP备案）后30日内办理本备案。

材料（各地略有差异）：备案申请表、营业执照、增值电信业务经营许可证或ICP备案号、法定代表人身份证。

流程：省级政务服务平台/窗口提交→受理→备案→公开，承诺时限约1～5个工作日。

3.3 入驻食品商家核验（平台义务）

每家上架食品商家核验：营业执照＋食品经营许可证（或预包装备案凭证、小作坊/小餐饮登记证等）。

餐饮现制商家须有实体经营门店，证照载明的经营场所与实际一致。

平台需建立商家资质审核与定期核验机制，并在提审材料中说明。

四、银行对公账户

材料：营业执照正本、法人身份证、印章（公章/财务章/法人章）、公司章程。

用途：微信认证打款验证、微信支付结算、日常经营收支。

周期：3～7个工作日；建议同时开通企业网银。

五、微信小程序账号、认证与备案

5.1 账号注册

微信公众平台注册小程序，选择“企业”主体，填写营业执照、法人信息、对公账户（小额打款验证）。

账号名称建议与公司名称或品牌一致，避免与已有主体冲突。

5.2 微信认证

费用300元/年；提交营业执照、对公账户信息、管理员信息。

周期1～3个工作日；认证通过后解锁支付、类目、部分接口能力。

5.3 小程序备案（工信部）

在小程序后台提交备案：主体信息、服务内容、法人信息、管理员信息。

注意：天津地区要求主体负责人必须是法定代表人。

流程：后台提交→微信平台初审→属地通信管理局审核→取得备案号；周期数个工作日。

六、类目选择与资质

以微信公众平台后台“类目库”实时信息为准，以下为主要对应关系：

| 业务 | 参考类目 | 资质要求 |
| --- | --- | --- |
| 家政/维修/养老/适老改造 | 生活服务-家政（家电维修/家政保洁等） | 营业执照经营范围包含家政服务等相关项目 |
| 平台型商家入驻 | 生活服务相关（平台型） | 需提供ICP许可证或ICP备案证 |
| 装修 | 以类目库实时为准（生活服务/房产相关） | 营业执照含装修相关；商家施工资质（如建筑装修装饰工程专业承包）作为入驻核验 |
| 食品 | 商家自营-食品饮料 | 四选一：食品经营许可证／食品生产许可证／预包装销售备案凭证等 |
| 自建房 | 以类目库实时为准 | 按对应服务场景补充 |

类目与小程序实际功能必须一致，不一致会被驳回。

平台型（第三方入驻）类目审核时需说明撮合模式并提交对应资质。

七、微信支付（服务商＋分账）

7.1 申请路径

登录微信公众平台→微信支付→服务商申请；提交营业执照、法人证件、对公账户、业务联系人信息。

流程：提交资料→审核→银行打款验证→在线签署协议→获得服务商商户号。

7.2 平台商户（分账）资质

平台撮合分账需开通“平台商户/合作工具箱”能力，资质要求：主体一致的ICP许可证或EDI许可证。

本项目需以经营性ICP证申请平台商户，取得后向入驻商家分账结算佣金。

分账能力：服务商模式下，通过分账API将交易款按比例分给入驻商家（分账接收方上限2万个）。

7.3 时序提示

支付开通不卡提审，但卡正式经营；因依赖ICP证，建议与增值电信并行推进。

八、自建服务器与域名

域名：以公司名义注册，用于小程序后端接口。

域名ICP备案：主体为公司，周期7～20天，尽早提交；小程序request合法域名必须是已备案的HTTPS域名。

服务器：境内云服务器（阿里云/腾讯云等），与备案主体一致。

HTTPS：申请SSL证书并配置，未配置HTTPS无法通过小程序请求校验。

开发/测试阶段：微信开发者工具可勾选“不校验合法域名”，上线前必须完成正式域名配置。

十二、总体排期与依赖关系

12.1 关键路径

营业执照 → 增值电信ICP申请（1～3个月，最长）→ ICP证 → 微信平台型类目＋支付平台商户＋网络食品平台备案

并行：域名注册备案（7～20天）→ HTTPS；小程序账号 → 认证 → 备案

提审材料（依赖ICP证、类目、备案、协议、体验版）→ 提交审核 → 发布

12.2 建议周排期

| 时间 | 主线动作 | 并行动作 |
| --- | --- | --- |
| 第1周 | 营业执照注册（经营范围写全、注册资本≥100万） | 域名注册＋域名ICP备案提交 |
| 第1～2周 | 增值电信申请材料准备 | 对公账户开立 |
| 第2～3周 | 提交增值电信ICP申请 | 小程序账号注册＋微信认证；食品经营许可证申请 |
| 第3～6周 | 等待ICP审批（期间推进开发） | 小程序备案；自建服务器部署＋HTTPS |
| ICP证取得后 | 网络食品平台备案（30日内） | 微信支付服务商＋平台商户（分账）申请 |
| 第6～10周 | 类目申请→提审材料→提交审核 | 体验版走查完善 |
| 第10周起 | 发布上线 | 上线前自检（备案号展示、支付链路、售后入口） |
