# 一、项目概述

## 1.1 项目定义

本项目为面向生活服务领域的小程序平台，以企业主体注册运营，采用“自营＋平台”混合模式：自营团队直接提供部分标准化服务（如家政保洁、家电维修、居家照护），同时开放第三方服务商入驻承接装修、自建房、适老改造等重交付业务，并支持食品等生活消费品在线销售。

本项目明确不涉及医疗服务：不提供诊疗、康复、理疗、用药指导等医疗行为，相关页面与文案一律避免使用医疗类表述，防止被归入医疗服务类目。

## 1.2 业务范围

| 业务板块 | 主要服务内容 | 交付形态 |
| --- | --- | --- |
| 家政服务 | 保姆、月嫂、日常保洁、深度清洁 | 自营＋平台 |
| 维修服务 | 家电维修、数码电器维修、水电维修、开锁换锁 | 自营为主 |
| 装修装饰 | 家庭装修、局部改造、自建房施工 | 平台入驻 |
| 自建房服务 | 自建房设计咨询、施工对接、材料采购 | 平台入驻 |
| 居家养老 | 助餐、助洁、助浴、陪护、日常照护 | 自营＋平台 |
| 适老改造 | 适老化产品零售、居家适老化改造施工 | 平台为主 |
| 食品销售 | 预包装食品、粮油、生鲜（按证照范围） | 自营＋平台 |

## 1.3 上线前提条件

① 营业执照经营范围覆盖全部实际业务（见 2.1 建议文本）；

② 完成微信认证、小程序备案；

③ 涉及食品销售的取得对应证照（见 2.4）；

④ 平台入驻模式下完成支付服务商资质与结算方案设计（见第四章）。

# 二、主体与资质准备

## 2.1 营业执照经营范围（建议文本）

以下为建议覆盖的表述，供与登记机关核对后写入经营范围；食品类经营范围须与实际证照一致，最终以登记机关核定为准。

家政服务；家庭服务；居民日常生活服务；

家用电器维修服务；家具安装和维修服务；开锁服务（涉及开锁业务的需具备公安备案）；

住宅室内装饰装修；建筑装饰装修工程施工；房屋建筑工程施工（自建房相关）；

建筑材料销售；五金产品零售；家用电器销售；

养老服务；老年人养护服务；居家养老服务；助餐、助洁、助浴服务；适老化改造服务；

食品销售（仅销售预包装食品）；食品互联网销售；

互联网信息服务；信息技术咨询服务；家政服务信息中介服务。

注意：如经营现制现售、生鲜等非预包装食品，需同步申请《食品经营许可证》，经营范围相应调整。

## 2.2 微信认证

| 事项 | 内容 | 说明 |
| --- | --- | --- |
| 认证主体 | 与营业执照主体完全一致 | 不一致将无法完成认证与提审 |
| 认证材料 | 营业执照、法人身份证、对公账户 | 对公账户用于打款验证 |
| 认证费用 | 300 元/年（微信官方收取） | 认证失败不退，提交前核对材料 |
| 认证周期 | 约 1～3 个工作日 | 审核期间可并行开发 |

## 2.3 类目-资质矩阵（核心）

依据微信开放文档《开放的服务类目》（2026年8月更新），各业务对应类目与资质要求如下。

| 业务 | 小程序类目 | 资质要求 | 特别注意 |
| --- | --- | --- | --- |
| 家政/保姆/月嫂/保洁 | 生活服务-家政服务 | 平台无强制资质 | 经营范围需含家政 |
| 家电/数码维修 | 生活服务-家政服务 | 平台无强制资质 | 维修师傅技能分级建议 |
| 开锁换锁 | 生活服务-家政服务（开锁） | 须为公安局备案开锁公司 | 需提供备案证明 |
| 装修/自建房施工 | 房地产服务-装修/装饰 | 平台无强制资质 | 经营范围需含装修/建筑 |
| 建材/五金/适老产品零售 | 商家自营-家装/五金/建材 | 平台无强制资质 | 危险化学品禁入；涉二类医疗器械需经营备案 |
| 食品销售 | 商家自营-食品饮料 | 4选1（见2.4） | 证照须与经营范围一致并公示 |
| 居家养老照护 | 生活服务-家政服务 | 平台无强制资质 | 护理员健康证＋养老护理技能（地方政策要求） |
| 平台型撮合（第三方入驻） | 各对应类目 | 建议评估增值电信业务许可证 | 支付需服务商模式，见第四章 |

## 2.4 食品类证照办理路径（4选1）

| 情形 | 证照 | 办理要点 |
| --- | --- | --- |
| 仅销售预包装食品（推荐起步） | 《仅销售预包装食品备案》 | 向属地市场监管部门备案即可，无需许可证，最快几天完成 |
| 经营一般食品（现制/冷藏等） | 《食品经营许可证》 | 需经营场所、设施与制度材料，办理周期约 2～4 周 |
| 自产自销食品 | 《食品生产许可证》 | 适用于生产企业自行生产并销售 |
| 口岸商店 | 《国境口岸卫生许可证》 | 仅特殊口岸场景 |

网络销售食品还须遵守《网络食品销售经营者落实食品安全主体责任监督管理规定》（市场监管总局令第124号，2026年施行）：入网销售者须取得相应许可或备案，并向平台提交真实证照，在小程序内向消费者公示。

## 2.5 平台型增值电信业务评估

自营业务不涉及增值电信业务许可；但平台型模式（为第三方服务商提供信息发布与交易撮合并收取费用）属于经营性互联网信息服务范畴，建议：

在启动前咨询属地通信管理局或专业服务机构，评估是否需要《增值电信业务经营许可证》（经营性ICP）；

若仅展示服务商信息、不收取信息服务费，风险相对较低，但仍建议书面确认口径。

# 三、备案与网络合规

## 3.1 小程序备案（工信部）

根据工信部要求，小程序上线前须完成备案。企业主体在微信公众平台“设置—服务内容声明—小程序备案”入口提交，由属地通信管理局审核。

| 项目 | 要求 |
| --- | --- |
| 主体材料 | 营业执照（统一社会信用代码）、法人身份证 |
| 负责人材料 | 小程序负责人身份证正反面、手机号 |
| 承诺书 | 真实性承诺书（系统自动生成，需确认信息） |
| 名称要求 | 小程序名称须符合单位性质且在经营范围内；未取得前置审批不得使用金融、医药、新闻等关键词 |
| 审核周期 | 初审即时，管局审核一般为数个工作日（以实际为准） |
| 一致性 | 备案主体必须与小程序注册主体100%一致 |

## 3.2 域名备案 与 云开发方案对比

| 方案 | 域名ICP备案 | HTTPS | 适用场景 |
| --- | --- | --- | --- |
| 微信云开发 | 无需域名备案 | 平台自动提供HTTPS | 快速起步、免运维；适合MVP与中小规模 |
| 自建服务器＋自有域名 | 需要（7～20天，需提前启动） | 需自行申请SSL证书并配置 | 对域名、数据自主可控要求高 |

## 3.3 HTTPS 与合法域名

小程序强制 HTTPS，请求域名须在小程序后台配置为 request/socket/uploadFile 合法域名白名单；

自建方案需在域名 ICP 备案完成后配置 SSL 证书（免费证书可用）；

涉及图片上传、文件下载的域名同样需要备案并加入白名单。

# 四、支付开通准备

## 4.1 自营收款（普通商户号）

申请微信支付普通商户号，绑定对公账户，费率按微信支付现行标准费率执行（以开通时官方规则为准）；

自营订单用户直接付款至平台商户号，T+1 结算至对公账户。

## 4.2 平台分账（服务商模式）

| 对比项 | 普通商户模式 | 服务商/特约商户模式 |
| --- | --- | --- |
| 收款主体 | 各入驻服务商自行申请商户号 | 服务商（平台）为特约商户代收代付 |
| 资金路径 | 用户→服务商商户号→服务商账户 | 用户→平台服务商商户号→按分账规则结算 |
| 适用 | 入驻商家少、各自结算 | 平台统一管控资金与分账（推荐） |
| 要求 | 商家自行完成商户号申请 | 平台需通过微信支付服务商资质审核 |

## 4.3 费率与结算要点

平台佣金抽成建议通过微信支付“分账”能力实现，平台先行收单再按约定比例分账给服务商；

大额预付（装修、改造）场景须设计资金托管/阶段验收付款规则，降低纠纷与投诉；

开通前与微信支付渠道商确认服务商资质要求、结算周期与分账手续费。

# 五、合规要点

## 5.1 隐私与个人信息保护

上线前配置《隐私政策》与隐私保护指引（微信后台填写收集信息清单）；收集手机号、定位、姓名等须逐项声明用途；

服务人员与用户个人信息（身份证、健康证等）仅限业务必需，落实最小化收集与访问控制。

## 5.2 协议体系

用户协议、隐私政策、退款规则、服务标准说明；

服务商入驻协议：资质承诺、服务标准、佣金结算、保证金、违约处理。

## 5.3 食品网络销售合规

按《网络食品销售经营者落实食品安全主体责任监督管理规定》取得许可/备案，向平台提交并在小程序内公示证照；

商品信息含名称、规格、保质期等法定要素；建立进货查验与售后处理机制。

## 5.4 家政与养老人员核验展示

依据商务部等9部门《关于促进家政服务消费扩容升级若干措施的通知》（2025年）精神，推进家政服务员信用信息核验；

建议在小程序展示服务员实名、健康证有效期、培训/技能证书；养老照护人员另须符合地方养老上门服务规范（健康证＋养老护理培训证明）。

## 5.5 内容安全与投诉机制

用户评论、服务商简介等UGC内容接入内容安全接口过滤；

设置客服入口、投诉通道与响应时限（建议24～48小时），留存处理记录。

# 九、风险与应对

| 风险 | 影响 | 应对措施 |
| --- | --- | --- |
| 经营范围不覆盖业务 | 认证/提审被拒 | 第1周先完成工商增项 |
| 食品证照办理周期长 | 拖后上线 | 预包装备案最快；许可证提前启动 |
| 平台模式资质合规风险 | 被要求整改/下架 | 提前咨询通信管理局；谨慎表述服务模式 |
| 支付服务商资质审核不通过 | 平台无法分账 | 自营先行上线，平台功能二期开放 |
| 类目政策调整 | 功能或类目被限制 | 关注官方类目公告，保留备用类目方案 |
| 养老业务被误判医疗 | 类目被改/驳回 | 全站文案规避医疗表述，纯生活照护 |
